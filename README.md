# 📝 Reminder

> 심플하고 깔끔한 Android TODO 앱

Reminder는 당신의 할 일을 쉽게 관리할 수 있는 네이티브 Android 애플리케이션입니다.
최신 Android 개발 기술을 사용하여 빠르고 안정적인 경험을 제공합니다.

## ✨ 주요 기능

- ✅ **할 일 관리** - 할 일을 추가하고, 수정하고, 완료 표시를 할 수 있어요
- 🎯 **우선순위 설정** - 중요도에 따라 높음/중간/낮음으로 구분
- 🏷️ **카테고리** - 할 일을 카테고리별로 정리
- 🔍 **빠른 검색** - 제목, 설명, 카테고리로 검색
- 📱 **Material Design 3** - 아름답고 직관적인 UI
- 🎨 **다크 모드** - Android 12+ 동적 컬러 지원
- 💾 **로컬 저장** - 인터넷 없이도 모든 데이터가 기기에 안전하게 보관

## 🚀 시작하기

### 요구사항

- Android 8.0 (API 26) 이상
- Android Studio Arctic Fox 이상 (개발자용)

### 설치 방법

1. **APK 다운로드** (릴리즈 페이지에서)
   ```
   곧 제공됩니다
   ```

2. **직접 빌드하기**
   ```bash
   # 저장소 클론
   git clone https://github.com/yourusername/reminder.git
   cd reminder

   # Android Studio에서 열거나 명령줄로 빌드
   ./gradlew assembleDebug

   # APK 위치: app/build/outputs/apk/debug/app-debug.apk
   ```

## 🎯 사용 방법

1. **할 일 추가하기**
   - 오른쪽 하단의 `+` 버튼을 눌러요
   - 제목과 설명을 입력하세요
   - 우선순위와 카테고리를 선택하세요
   - "Add Reminder" 버튼을 누르면 완료!

2. **할 일 완료하기**
   - 할 일 옆의 체크박스를 눌러요
   - 완료된 항목은 취소선으로 표시됩니다

3. **할 일 수정/삭제하기**
   - 할 일을 터치하면 수정할 수 있어요
   - 휴지통 아이콘을 누르면 삭제됩니다

4. **검색하기**
   - 상단의 검색 아이콘을 눌러요
   - 찾고 싶은 내용을 입력하세요

## 🛠️ 기술 스택

이 앱은 최신 Android 개발 베스트 프랙티스를 따릅니다:

- **데이터베이스**: Room
- **비동기 처리**: Coroutines & Flow
- **디자인**: Material Design 3
