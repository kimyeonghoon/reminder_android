# 📱 리마인더 앱 - 간단 테스트 (70대 어르신용)

**v1.63.0 - 이제 100% 한글입니다!** 🎉

---

## 📋 7단계로 끝내는 간단 테스트 (총 40분)

### 1️⃣ 앱 열기 (5분)
- 휴대폰에서 "Reminder" 앱 찾기
- 앱 누르기
- 화면 아래 "홈, 통계, 포모도로, 집중, 습관" 메뉴 보이는지 확인
- ✅ **영어가 하나도 없는지 확인!**

---

### 2️⃣ 할 일 추가 (10분)
- 오른쪽 아래 파란색 "리마인더 추가" 버튼 누르기
- **제목**: "병원 가기" 입력
- **설명**: "오후 2시 정형외과" 입력
- 날짜 선택 → 내일 날짜 선택
- "리마인더 추가" 버튼 누르기
- ✅ 목록에 추가되었는지 확인

---

### 3️⃣ 중요도 필터 (5분)
- 화면 위 "중요도" 찾기
- "전체, 높음, 중간, 낮음" 버튼 확인
- "높음" 눌러보기
- "전체" 다시 눌러보기
- ✅ **한글로 되어 있는지 확인!**

---

### 4️⃣ 날짜 필터 (5분)
- "날짜" 찾기
- "전체, 오늘, 이번 주, 이번 달, 지난 일정" 버튼 확인
- "오늘" 눌러보기
- "전체" 다시 눌러보기
- ✅ **한글로 되어 있는지 확인!**

---

### 5️⃣ 정렬 (5분)
- "정렬" 찾기
- 버튼 눌러서 메뉴 보기
- "중요도 (높은 순)" 선택해보기
- "날짜 (빠른 순)" 다시 선택
- ✅ **한글로 되어 있는지 확인!**

---

### 6️⃣ 검색 (5분)
- 화면 위 돋보기(🔍) 누르기
- "리마인더 검색..." 칸에 "병원" 입력
- 검색 결과 확인
- ✅ **"리마인더 검색..."이 한글인지 확인!**

---

### 7️⃣ 완료하기 (3분)
- 할 일 왼쪽 동그라미 누르기
- 체크 표시 생기는지 확인
- 5초 후 사라지는지 확인
