## 🎯 테스트 시나리오 1: 완전한 사용자 플로우

### 시나리오 1.1: 리마인더 생성 → 완료 → 삭제
**목표**: 기본 CRUD 기능 검증

**단계**:
1. 앱 시작 (홈 화면)
2. FAB 버튼 클릭 ("리마인더 추가")
3. 새 리마인더 입력
   - 제목: "AI 테스트 리마인더"
   - 설명: "자동화 테스트입니다"
   - 우선순위: HIGH
   - 긴급도: HIGH
4. 저장 (뒤로가기)
5. 홈 화면에서 리마인더 확인
6. 체크박스 클릭 → 완료 처리
7. "습관" 탭 이동 → 완료 내역 확인
8. 홈으로 돌아와서 삭제

**예상 결과**:
- ✅ 리마인더가 정상적으로 생성됨
- ✅ 완료 처리 시 체크 표시
- ✅ 삭제 후 목록에서 제거됨
